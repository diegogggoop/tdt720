# tdt720

Manifiestos DASH de los canales nacionales de TDT limitados a 720p (para reproducir por software en una TV
sin que el procesador de imagen se quede a 50 Hz). Copias de los de
[FreakinGuns/listacanalestdtiptv](https://github.com/FreakinGuns/listacanalestdtiptv) sin la calidad 1080p;
el vídeo sale de los servidores oficiales de cada cadena.

## Lista completa

`lista-buena.m3u`: 80 canales a 720p como máximo (TDT, cine y series, temáticos, autonómicos, internacionales), todos de
emisiones oficiales o plataformas gratuitas legales. Para cargarla en un reproductor IPTV:

    https://cdn.jsdelivr.net/gh/diegogggoop/tdt720@main/lista-buena.m3u
